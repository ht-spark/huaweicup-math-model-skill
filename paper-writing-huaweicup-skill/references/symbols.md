# 符号说明

## 职责

统一全文复用的变量、参数、集合、缩写和单位，使模型表达可独立阅读且前后一致。

## 写作顺序

1. 优先列出跨多个小问共用的符号。
2. 对每个符号给出名称、含义、单位或取值范围。
3. 局部符号在对应小问首次出现处定义，避免总表膨胀。
4. 与 `modeling_output/说明文档/结果说明.md` 和 `建模证据清单.yaml` 保持同一命名。

## 边界

不混用同一符号表示不同概念；不遗漏单位；不把代码变量名直接当作论文符号。

## 落地示例

### 示例：只收录跨章节复用的符号

**适用场景**：多个小问共享对象集合、决策变量和评价指标。

| 符号 | 含义 | 单位或取值范围 |
| --- | --- | --- |
| $I$ | 待分配对象的索引集合 | — |
| $J$ | 候选服务节点的索引集合 | — |
| $x_{ij}$ | 对象 $i$ 是否由节点 $j$ 服务 | $\{0,1\}$ |
| $d_{ij}$ | 对象 $i$ 到节点 $j$ 的实际距离 | km |
| $C_j$ | 节点 $j$ 的最大服务能力 | 件/日 |
| $R$ | 方案相对基线的排名重合率 | % |

正文首次使用时写为：“令 $x_{ij}=1$ 表示对象 $i$ 分配至节点 $j$，否则 $x_{ij}=0$。”若后续只在灵敏度分析中使用扰动比例 $\delta$，则在该小节首次出现处定义，不再扩充总表。

**写法解析**：集合、决策变量、参数和指标分工清楚；含义能够脱离代码阅读；量纲或取值范围与符号同时出现。

**可复用结构**：符号 → 可判定的含义 → 单位/范围；局部符号就地定义。

**使用边界**：表中的符号仅示范粒度，不得直接移入当前论文。若当前模型已使用其他命名，应服从建模证据并保持全文一致。

*范文依据：归纳自 C23910020010、F22105330345 的符号表形式，并针对原范文常见的符号过量和单位缺失问题作了收缩。*
