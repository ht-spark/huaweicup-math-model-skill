# 小问分析

## 职责

回答“本问为什么采用这一类处理方式”，把题目要求、数据特征和模型选择连接起来。

## 写作顺序

1. 重申本问的目标、输出和约束，不重复整段题面。
2. 指出本问使用的数据、前序结果或业务机制。
3. 识别关键变量、关系、难点和评价标准。
4. 说明候选处理思路，并论证最终模型为何与本题事实相符。

## 边界

不先贴题型标签再罗列算法；不将模型名称当作选择理由；不在证据不足时宣称模型优越。

## 落地示例

### 示例：从任务矛盾推导模型类型

**适用场景**：资源分配、选址或调度问题同时包含覆盖、均衡和成本要求。

> 本问需要在【资源总量】固定的条件下，为【对象集合】确定【分配/选址】方案。题目的难点不只是降低【成本指标】，还要同时满足每个对象被完整覆盖、各节点负荷不超过容量以及服务差异尽量均衡。附件给出的【距离/需求/容量】可分别对应运输代价、对象权重和节点上限，因此可将方案表示为 0–1 决策矩阵。随机分配虽能产生可行解，但不能稳定控制最差负荷和总体成本；连续模型又无法表达“选择或不选择”的离散决策。基于这些事实，本问采用带容量约束的多目标整数规划，并用【已实际采用的求解方法】搜索可行方案。方案优劣统一由【指标一】、【指标二】和约束违反数评价。

**写法解析**：先把题目要求翻译成变量、目标和约束，再通过候选方法不能覆盖的关键要求说明选择理由；评价标准在求解前确定。

**可复用结构**：任务目标 → 数据可表达的关系 → 关键冲突与难点 → 候选思路比较 → 最终模型类别与评价指标。

**使用边界**：模型名称必须来自当前建模成果。若没有做候选方法比较，可说明该方法为何满足题目结构，但不能虚构基线实验或“最优性”。

*范文依据：归纳自 C23910020010 对作品交叉分配难点的分析和 F22105330345 对多层级选址—配送关系的拆解。*
