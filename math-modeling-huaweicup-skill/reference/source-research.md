# 当前小问的资料检索与来源管理

资料检索服务于当前小问的具体证据缺口，不做与求解无关的泛化综述。优先级通常为：比赛题目与当届规范 > 政府、监管机构、标准组织或数据发布机构 > 原始同行评议论文/作者预印本 > 权威技术文档 > 高质量二手资料。

## 检索前

先写清需要补足的内容及其用途，例如：某参数的合法区间、行业计算公式、公开统计数据、方法原始定义或评价指标。能够由题目、附件或用户模型直接确定的内容不重复外查。

## 使用来源

- 官方统计或外部数据应记录发布机构、数据集名称、版本/时间范围、字段、单位、URL、本地落盘路径和访问日期。
- 论文应优先核对 DOI、作者、题名、年份和发表载体；只引用实际读到并能支撑当前陈述的内容。
- 标准、法规和比赛规则应核对适用地区、版本和生效时间。若信息可能变化，应使用当前有效的官方版本。
- 外部数据进入求解前，检查其口径、时间/空间粒度、单位、许可和与题目数据的连接方式；不得仅因可获得就拼接。
- 不自动绕过付费墙、登录、访问控制或许可限制，不把搜索摘要当作已核实的全文证据。

## 资料来源清单

在 `modeling_output/说明文档/资料来源清单.md` 中按当前小问记录：

| 字段 | 内容 |
|---|---|
| 来源 | 题名或数据集/标准名称 |
| 作者/机构 | 作者或发布机构 |
| 日期 | 发表、发布或更新日期 |
| 类型 | 官方资料、数据、论文、标准、技术文档等 |
| 定位 | URL、DOI 或 `upload_material/` 本地路径 |
| 访问日期 | 实际访问日期 |
| 支撑内容 | 被该来源直接支撑的事实、参数、公式或方法 |
| 使用位置 | 对应小问及代码、结果说明或表格位置 |
| 状态 | 已用于实现、仅背景、存在冲突或待核实 |

若引用只支持方法存在，不能据此声称它适合本题；适配性仍须由题意、机理、数据画像和验证结果证明。若权威来源与用户模型冲突，在人工审核包中并列呈现二者及可能影响。
