# 求解与检验清单

按新流程五个阶段逐项核对；每阶段核对通过才进入下一阶段。

## Step 1 读题核对

- [ ] 题目背景与业务目标已用自己的话复述
- [ ] 每个小问的要求（决策量 / 预测量 / 评价值 / 证明）已明确
- [ ] 小问之间的依赖关系已梳理
- [ ] 题目要求的输出物清单已逐条划出

## Step 2 数据画像核对

- [ ] 规模与结构：行列数、字段含义、主键、时间 / 空间粒度
- [ ] 质量：缺失比例与分布、异常值识别方式与处理、重复记录
- [ ] 统计特征：分布、量纲、相关性、时序性 / 空间性 / 网络性
- [ ] 与问题的关联：字段与题目要求量的对应关系，缺失量如何推导
- [ ] 画像结论已记录（它直接约束模型选择）

## Step 3 建模思考核对

- [ ] 模型从题目机理推导，**不是**先贴类别标签再选方法
- [ ] 候选模型与本题假设的吻合度已逐条论证
- [ ] 数据画像结论已用于筛选模型（样本量、时序性、噪声）
- [ ] 符号表（符号、含义、单位）与数学表达完整
- [ ] "为什么这个模型适配本题"的论证已写出
- [ ] 思考成型后再用本清单核对遗漏，不以方法手册替代从题目机理出发的建模论证

## Step 3A 建模验证核对（编码前）

- [ ] 输入、决策变量、输出与题目要求逐项映射；单位、边界、数量级一致
- [ ] 每个关键假设都有题干或数据证据支撑，并写明不满足时的适用边界
- [ ] 已设定简单、可解释的基线或对照方案
- [ ] 已检查参数可估计、约束可行，且训练/验证/测试划分没有信息泄漏
- [ ] 验证口径已预先确定：对照对象、指标、验证切分或模拟方案，以及结论失效的判据

## Step 4-5 求解与产出核对

- [ ] 固定随机种子 `SEED = 42`
- [ ] 超参数与求解器配置已记录
- [ ] 启发式算法先用小算例对照精确解
- [ ] 图片（适用时）按 `figure-integration.md` 的内置 Python 规范生成：统一配色、中文、坐标轴带单位、PNG 300 dpi；重点图额外导出 PDF 或 SVG，并完成渲染后的可读性与遮挡检查
- [ ] 题目要求的输出结果已按题目格式生成；无规定格式用 CSV + 表头说明

## Step 4A 代码与运行产物验证核对

- [ ] 已检查字段映射、缺失值、单位换算、索引对齐和数据切分
- [ ] 核心公式已用手算或独立小算例验证；约束、守恒、非负性等不变量通过检查
- [ ] 已记录求解器状态、收敛条件、运行时间、随机种子和超参数
- [ ] 启发式或随机算法已做多次独立运行，并和小规模精确解、界或可行基线对照
- [ ] 已按任务类型执行效果验证（测试集/滚动验证、排序稳定性、拟合残差、可行性和最优性界等）
- [ ] 已完成关键参数、数据扰动或题意情景下的稳健性检查
- [ ] 已重跑代码，并抽查说明、图表和结果文件中的数值可追溯到运行产物

## Step 6 说明文档核对

- [ ] 产物清单：每个输出文件 / 图的路径
- [ ] 产物含义：数值结果的具体解释
- [ ] 模型说明：假设、符号、数学结构、求解方法与配置
- [ ] 建模思路：从题目机理和数据特点到模型选择的推理链条
- [ ] 检验结论齐全（见下表）

## 检验项（按模型类型执行对应项）

| 模型类型 | 必做检验 |
|---|---|
| 预测 | RMSE / MAE / MAPE / R²，残差图，时序做滚动验证 |
| 评价 | 权重分布合理性；换定权法后排序变化（Kendall tau） |
| 优化 | 约束满足校验；松弛界或对偶界 gap；多起点防局部最优 |
| 分类聚类 | 混淆矩阵 / F1；轮廓系数或肘部法定 k |
| 机理模型 | 参数拟合 R²；与实测数据对照；步长减半结果不变 |

## 灵敏度分析

方法：单因素扰动（OAT），关键参数取 ±5% / ±10%。

报告格式：

| 参数 | 基准值 | 扰动 | 结果变化 | 结论是否翻转 |
|---|---|---|---|---|

判据：结论不翻转 = 模型稳健；翻转 = 声明适用区间，或回 Step 3 重新思考模型。

## 常见坑

- 不读题不画像，直接按"类别"套模板方法
- 数据泄漏：用了测试期或未来信息训练
- 过拟合：小样本上了复杂模型
- 量纲未归一化，权重或距离失真
- 启发式未验证收敛，结果不可复现
- 插值/拟合混用；超数据范围外推仍给精确结论
- 只交数值结果，没有图和说明文档
